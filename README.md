# Sistema de Organización de Proyectos para Grupos de Investigación

¡Bienvenido! Este es un *vault* (bóveda) de **Obsidian** configurado profesionalmente para centralizar, gestionar y evaluar las actividades de los grupos de investigación universitarios. 

El sistema permite vincular de forma inteligente a los investigadores con sus respectivos proyectos, realizar un seguimiento visual del progreso y gestionar las calificaciones de manera dinámica.

---

## Características Clave

* **Registro de Integrantes:** Perfiles detallados de investigadores, estudiantes y asesores con asignación de roles.
* **Gestión de Proyectos:** Seguimiento exhaustivo de líneas de investigación, entregables y estados de desarrollo.
* **Dashboards Dinámicos:** Paneles de control visuales para monitorear proyectos activos, avances generales e integrantes en tiempo real.
* **Control de Calificación:** Un apartado automatizado y dinámico para evaluar el desempeño, avances y cumplimiento de objetivos de cada proyecto o integrante.
* **Estructura Interconectada:** Uso de enlaces bidireccionales para que nunca pierdas el contexto entre un alumno, su avance y su nota.

---

## Requisitos e Instalación

Para que los paneles dinámicos funcionen correctamente, es necesario tener instalados ciertos plugins comunitarios de Obsidian.

### 1. Clonar o Descargar el Repositorio
Descarga este repositorio como archivo ZIP y descomprímelo, o clónalo usando Git:
```bash
git clone https://github.com/Danteeh/Investigations_Group_Vault_For_admins.git
```

### 2. Plugins Necesarios
Si decides abrir esta carpeta como una bóveda nueva en Obsidian, asegúrate de activar los **Plugins Comunitarios** en la configuración. El sistema depende de:
* **Dataview**
* Spreadsheet Table
* **Templater**
+ Table Exporter
### 3. Instrucciones de Uso
1. Abre **Obsidian**.
2. Selecciona **"Abrir carpeta como bóveda"** (*Open folder as vault*).
3. Selecciona la carpeta raíz de este proyecto.
4. Explora la nota principal Dashboard.md`
